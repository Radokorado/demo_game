# Prototype — Rado

## Overview
A small interactive prototype built in Godot 4 using GDScript.
Built as part of a development task — focused on clean execution and good game feel.

## Features
- Player movement
- Shooting mechanic
- Enemies with basic shooting AI
- Player health system
- Healing item
- Main menu and settings screen

## Project Structure
/scenes      — all scenes separated by purpose
/scripts     — all scripts, one responsibility per file
/assets      — sprites and audio

## Notes
The base scene structure was carried over from an existing personal project.
All gameplay systems (movement, combat, health, enemies, UI) were built for this task.

## Controls
WASD — Move
Left Click / [key] — Shoot
[key] — Interact

## Built with
- Godot 4.6.2
- GDScript
